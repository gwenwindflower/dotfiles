# Learning mode

Off by default. A request to enable learning mode, or invoking this skill without arguments, turns it on for the session. `on` enables it; `off` stops the active exercise and all exercise offers immediately. Confirm the toggle briefly. Reading this skill for maintenance or receiving an automation nudge does not enable it.

While on, offer optional 10–15 minute exercises after architectural decisions, schema changes, unfamiliar patterns, or work that prompted the user's “why” questions. Keep each offer to one sentence and wait for acceptance. Continue ordinary task work between exercises.

Stop unsolicited offers after a decline or two completed exercises in the session. Explicit exercise requests remain welcome; toggling the mode does not reset those limits. A new session starts off.

| Job | Module |
| --- | --- |
| Run an exercise or adjust its difficulty | [Facilitation](PRINCIPLES.md) |
| Configure optional commit reminders | [Automation](automation.md) |

During an exercise, ask one question, then end the turn and wait. Do not reveal the answer, suggest responses, or continue the walkthrough before the user replies.
