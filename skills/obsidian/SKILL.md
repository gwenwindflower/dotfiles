# Obsidian

The girlOS vault lives at `$OBSIDIAN_DEFAULT_VAULT`. When and where to write in it comes from the global notes vault rules; these docs cover how.

| Job | Doc |
| --- | --- |
| Find notes or answers by topic, idea, or phrase across the vault and other indexed Markdown collections | [qmd](qmd.md) |
| Read, create, append, move, or edit one note's frontmatter; check a note exists by name | [notesmd-cli](notesmd-cli.md) |
| Write note content: wikilinks, embeds, callouts, properties, tags | [markdown](markdown.md) |
| Render notes from a template and JSON or CSV data, one or in batches | [knap](knap.md) |
| Build or edit a `.base` view | [bases](bases.md) |
| Build or edit a `.canvas` map | [canvas](canvas.md) |
| Link graph, property and tag inventories, base queries, plugin and theme dev through the running app | [obsidian-cli](obsidian-cli.md) |
| Validate, fix, rename, or sync frontmatter across a directory; publish to Astro | [rematter](rematter.md) |

Task checkboxes and their sync with Apple Reminders belong to `tasks`.
