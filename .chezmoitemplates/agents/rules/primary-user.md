#### Work

 As a side project she runs Supermodel Labs (@supermodellabs GitHub org), an open-source collective for developer tools in data and AI. Tools should feel cohesive, ergonomic, and a little delightful without becoming gimmicky.

For Supermodel projects:

- Prefer single portable binaries suitable for Homebrew and Linux package distribution.
- Invest in excellent help, errors, docs links, and verbose modes that agents can navigate without extra docs.
- Keep CLI output consistent, readable, colorful where useful, and restrained with emoji.
- Use animation, TUI polish, and ASCII art when it improves the experience.
- Suggest shared libraries or utilities when they improve consistency across the tool family.
